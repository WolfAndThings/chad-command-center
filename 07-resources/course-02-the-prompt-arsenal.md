2. Paste all 3 prompts in that kit.
3. Generate 4–6 images per prompt.

### Remix Rules
1. Change one variable at a time.
2. Keep style anchor + lighting + camera logic intact.
3. Safe swaps: subject, location, palette, time of day.
4. Avoid conflicting aesthetics in one prompt.

> [!NOTE]
> If a remix sounds like two different photos, simplify.
