## Project 1: Build Your Influencer
### Create One Locked AI Character With LoRA + Voice
**Deliverable:** Complete AI influencer with trained LoRA and locked voice profile.

### Why AI Faces Fail
| Problem | Looks Like | Fix |
|---|---|---|
| Plastic skin | Smooth, waxy, pore-less | Skin realism layer |
| Dead eyes | Flat, unfocused, lifeless | Catchlight requirements |
| Too perfect | Uncanny symmetry | Asymmetry in DNA |
| Frozen | Unnatural expression | Mid-moment capture |
| Inconsistent | Different face each time | LoRA training |

### Step 1: Build the DNA Profile
Every consistent character starts with a short description: 8 lines.

```txt
CHARACTER DNA - [NAME]
===============================================================
Age / Gender / Ethnicity: [e.g. "28, female, mixed Black / Southeast Asian"]
Build: [e.g. "athletic-lean, average height"]
Face: [2-3 defining features - "oval face, high cheekbones, full lips"]
Skin: [tone + one texture note - "medium warm brown, visible pores on nose"]
Unique mark: [the thing that locks them - "beauty mark below left eye"]
Eyes: [color + shape - "deep brown, almond, slight upward tilt"]
Hair: [color, texture, length - "dark brown, loose curly, past shoulders"]
Wardrobe: [signature look - "cream oversized sweater, gold hoops"]
===============================================================
```

### Example: Maya
```txt
CHARACTER DNA - "Maya"
===============================================================
Age / Gender / Ethnicity: 28, female, mixed Black / Southeast Asian
Build: Athletic-lean, average height
Face: Oval face, defined jawline, high cheekbones, full lips
Skin: Medium warm brown with golden undertones, visible pores on nose
Unique mark: Small beauty mark below left eye, three freckles across nose
Eyes: Deep brown, almond shape, slight upward tilt
Hair: Dark brown loose curly (3A), just past shoulders, baby hairs at temples
Wardrobe: Oversized cream knit sweater, small gold hoops, earth tones
===============================================================
```

### Step 2: Define Their Brand
```txt
INFLUENCER BRAND - [NAME]
===============================================================
Niche: [what they talk about]
Vibe: [how they feel]
Content pillars: [3-4 recurring themes]
Aesthetic: [visual style]
Platform voice: [how they talk]
===============================================================
```

### Step 3: Generate Hero Portraits
Use Weavy Nano and convert DNA into a portrait prompt.

```txt
Portrait photograph of a 28-year-old mixed Black and Southeast Asian woman,
oval face with defined jawline, high cheekbones, full lips,

medium warm brown skin with golden undertones,
visible pores on nose, natural skin texture,
small beauty mark below left eye,
three freckles across nose bridge,
no artificial smoothing,

deep brown almond eyes with slight upward tilt,
catchlight visible in upper iris,

dark brown loose curly hair just past shoulders,
baby hairs at temples,

warm half-smile, eyes engaged,

wearing cream oversized knit sweater, small gold hoops,
soft natural window light from camera left,
simple neutral background,
shoulders-up framing, slight 3/4 angle,

shot on Sony A7IV with 85mm f/1.8 at f/2.8,
shallow depth of field,
natural color grading,
authentic portrait photography
```

Generate 8-12 portraits and select the best 2-3.

### Step 4: Build Reference Sheets
Create three sheets:
1. **Angles (4 views)**
2. **Expressions (9 faces)**
3. **Full body (3 poses)**

| Sheet | What It Locks | Use Case |
|---|---|---|
| Angles | Face from all sides | Any camera position |
| Expressions | Emotional range | Different content moods |
| Full Body | Proportions, style | Lifestyle, wider shots |

### Step 5: Train Your LoRA
Prepare a 15-25 image set and train inside Weavy LoRA Training.

```txt
TRAINING SET (15-25 images)
├── Hero portraits (3-5)
├── Angles sheet panels (4)
├── Expression samples (4-6)
├── Full body shots (3)
├── Varied lighting (2-3)
└── Varied backgrounds (2-3)
```

Trigger words:
- Good: `mymaya`, `char_marcus`, `ugc_maya`
- Bad: `maya`, `woman`, `person`, `portrait`

### Step 6: Lock the Voice
Use ElevenLabs Voice Lab -> Voice Design and save a consistent character voice profile.

## Project 4: Video + Voice Production
### Turn Best Stills Into Video With Voice
**Deliverable:** 10 clips (5 voiceover + 5 ambient loops).

### Pipeline
```txt
Best Still
-> Weavy (Veo 3 / Sora)
-> ElevenLabs voiceover
-> Sync in editor
-> Platform exports
```

### Veo 3 vs Sora
| Use Case | Best Tool | Why |
|---|---|---|
| Talking head / testimonial | Veo 3 | Better facial consistency |
| Ambient lifestyle loops | Either | Both handle subtle motion |
| Hands / product interaction | Sora | Better hand preservation |
| Fast turnaround | Veo 3 | Faster retries |

### Motion Prompt Templates
**Talking head:** natural blinks, slight nods, micro-expressions, 3-5 seconds.

**Ambient loops:** subtle steam/hair/fabric movement, grounded breathing, loop-friendly 3-5 seconds.

### QC Checklist
| Check | Pass? |
|---|---|
| Face consistent through clip? | |
| No morphing/distortion? | |
| Motion weighted, not floaty? | |
| Hands stable? | |
| Voice matches face? | |
| Loop point clean? | |

### Troubleshooting
| Problem | Fix |
|---|---|
| Face morphs | Crop tighter, reduce motion |
| Hands distort | Crop out / use Sora |
| Floaty movement | Add "weighted, grounded" |
| Voice mismatch | Adjust ElevenLabs age/tone |

### Platform Specs
| Platform | Aspect Ratio | Resolution | Max Length |
|---|---|---|---|
| Instagram Reels | 9:16 | 1080x1920 | 90 sec |
| TikTok | 9:16 | 1080x1920 | 60 sec |
| YouTube Shorts | 9:16 | 1080x1920 | 60 sec |
| Feed Clips | 1:1 / 4:5 | 1080x1080 / 1080x1350 | 60 sec |
