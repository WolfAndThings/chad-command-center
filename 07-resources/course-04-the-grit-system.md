## The GRIT Framework (QC)
| Element | Core Question | If Missing |
|---|---|---|
| Flash | Is light harsh and directional? | Add on-camera flash + hard shadow |
| Grain | Is analog texture visible? | Name film stock + camera |
| Motion | Is time present in frame? | Add mid-action + motion blur |
| Texture | Does it survive zoom? | Add pores/sweat/scuffs/dust |
| Color | Is hierarchy clear? | Mute palette, keep one anchor |

> [!TIP]
> If output feels flat, fix the weakest two GRIT elements first.
